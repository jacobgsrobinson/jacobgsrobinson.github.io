Privacy Policy

Hermes Fleet Automations · Last updated: 14 October 2026

1. Who this covers

Hermes Fleet Automations is a private, single-user automation system ("the app"). It runs on a server owned and operated by its sole user, and it accesses only that user's own Google account (jgsrgameing@gmail.com). There are no other users, no sign-ups, and no third-party accounts connected to it.

2. What Google user data the app accesses

With the user's explicit consent, the app requests these scopes and uses them solely to automate the user's own workflows:

  • Gmail (read, modify, send) — to surface and send the user's own email on the user's instruction.
  • Google Drive — to read and write the user's own files and folders.
  • Google Sheets — to read and update the user's own spreadsheets.
  • Google Docs — to create and update the user's own documents.
  • Google Calendar — to read and manage the user's own calendar.
  • Google Contacts (read-only) — to resolve the user's own contacts.
  • YouTube (read, upload, manage, read analytics) — to publish and analyse the user's own channel.

No data is requested from, or collected about, anyone who is not the user.

3. How Google user data is used

Data is used only to perform the automation the user asks for (for example: watch a Drive folder for new files and notify the user; update a personal spreadsheet; publish a video the user has approved). It is never used for advertising, profiling, resale, or any purpose unrelated to that automation.

4. Storage, sharing and retention

  • OAuth credentials and any working files are stored locally on the user's own server, protected by filesystem permissions; credentials are not stored anywhere else.
  • No Google user data is shared, sold, or transferred to any third party. No data is sent to any external service, and none is used to train machine-learning models.
  • Working data is retained only as long as it is needed for the automation, and the user may delete it at any time.

5. Limited Use disclosure

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

6. Revoking access

The user can revoke the app's access at any time at myaccount.google.com/permissions. Once revoked, the stored credentials stop working immediately and no further data is accessed.
